## 与变量结构的关系

字段路径必须与 `variable-schema.js` 一致（`世界.*` / `玩家.*` / `人物.*` / `在场.*` / `委托.*` / `料理.*`）。
schema 增删字段后，这里要跟着改，否则面板会显示不存在的路径。
